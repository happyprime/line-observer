LineObserver demos

Each page loads ../build/line-observer.js. Run npx rollup -c first. The check pages run their cases on load when the URL has ?check, or when you press Run check.

  • Scroll-triggered animations: the main demo.
  • Offset after a jump (check): an element that activates after a jump gets an offset from its top edge, in the same frame.
  • Layout changes at rest (check): an active element moved off the line by a layout change deactivates, and a pass at rest leaves other active elements alone.
  • Direction after jumps (check): activateFrom follows the last move, even when the page moved while the loop was stopped.
  • Callback errors (check): a callback that throws does not stop the loop, and an element a callback unregisters gets no more writes.
  • The loop at rest (check): the loop stops a few frames after the page comes to rest, and a scroll, an anchor link or a layout change starts it again.
  • Progress (check): --scroll-progress follows the element's position, holds 1 past the line and 0 below it, and counts the height an element grows to.
  • Reveal once (check, which loads the page again at #c6): cards and headings revealed with once show after a load partway down, a fast flick, a filter that adds cards above, and a jump past them and back. A section that is not once holds is-passed.
  • Many elements, three observers (check): 300 elements over three observers with different lines share one loop and six IntersectionObservers. Every element activates and deactivates in order, no frame reads the page after writing to it, and destroying one observer leaves the other two working.
  • Resize (check): a height that goes back and forth, as a phone's toolbar shows and hides, leaves an element that activateFrom holds active held, and a width-only resize builds no IntersectionObserver. The check changes the viewport: in a headless run the runner does it, and by hand you set the sizes the page asks for with the device toolbar.
  • Option values (check): elements registered from data- attributes, as a block's script would, turn on at their own lines. A string of digits is a number, a missing attribute keeps the default, and each invalid value logs one warning.
