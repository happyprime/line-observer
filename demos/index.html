LineObserver demos

Each page loads ../build/line-observer.js. Run npx rollup -c first. The check pages run their cases on load when the URL has ?check, or when you press Run check.

  • Scroll-triggered animations: the main demo.
  • Offset after a jump (check): an element that activates after a jump gets an offset from its top edge, in the same frame.
  • Layout changes at rest (check): an active element moved off the line by a layout change deactivates, and a pass at rest leaves other active elements alone.
  • Direction after jumps (check): activateFrom follows the last move, even when the page moved while the loop was stopped.
